Установка

Три шага — и
в игре

Без аккаунтов, без телеметрии, без лишних окон.

Скачайте

Один файл FramePulse-Setup.exe (~2.3 MB). От администратора — для глобальных хоткеев.

Запустите

Оверлей сразу в трее. Настройки — ПКМ по иконке → «Настройки…». Всё применяется live.

Играйте

FPS, ЦП, ГП и память поверх окна. Перетаскивание — Ctrl+Shift+F12.

Вопросы

FAQ

Эксклюзивный fullscreen often «перекрывает» overlay-окна. Переключи игру в оконный или безрамочный (borderless) режим — тогда FramePulse будет поверх.
Оверлей перерисовывается раз в 500 мс и почти не ест CPU/GPU. PresentMon работает отдельным лёгким процессом. Влияние на FPS — менее 1%.
Настройки → поле «Процесс». Пусто = активное окно (авто). Либо впиши имя: cs2.exe, VALORANT-Win64-Shipping.exe и т.д. После смены — «Перезапустить PresentMon».
%APPDATA%\FpsOverlay\config.ini — простой текстовый файл, можно править вручную или переносить между ПК.
Глобальные хоткеи (Ctrl+Shift+F10–F12) должны работать поверх полноэкранных игр — для этого окну нужен соответствующий уровень привилегий (манифест).
FPS, ЦП, ОЗУ и время кадра — да. Температура/VRAM/загрузка ГП сейчас через NVML (NVIDIA). Для AMD можно расширить монитор — исходники открыты.
