# FramePulse

Лёгкий игровой оверлей для Windows: FPS, время кадра, ЦП, ГП, температура и память поверх игры.

## Быстрый старт

1. Скачайте `FramePulse-Setup.exe` из [Releases](../../releases)
2. Запустите **от администратора**
3. Играйте — данные обновляются в реальном времени

## Горячие клавиши

- `Ctrl+Shift+F10` — скрыть/показать
- `Ctrl+Shift+F11` — следующий монитор
- `Ctrl+Shift+F12` — перетаскивание

## Сборка

```bat
build.bat
```
